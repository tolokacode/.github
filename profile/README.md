# tolokacode

Free, open-source plugins and tools for the services shops in Ukraine use, like monobank.

*Toloka* (толока) is an old Ukrainian tradition. When someone needed to build a house or bring
in the harvest, the whole village came to help, for free. We do the same with code.

## Projects

| Project | What it does |
|---|---|
| [toloka-monobank](https://github.com/tolokacode/toloka-monobank) | WooCommerce plugin: monobank installments (Покупка частинами) and cash on delivery with online prepayment. Works alongside the official "plata by mono" plugin. |

More to come: plugins, Python and Django packages, command-line tools.
