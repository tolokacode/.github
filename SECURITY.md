# Security

Some of our projects handle payments, so a security bug can cost people real money.

## Reporting a problem

**Please don't open a public issue.** Go to the repository's **Security** tab and click
**Report a vulnerability**. Only the maintainers will see it.

Tell us what the problem is, how to reproduce it and what could happen. We'll reply as soon as
we can, fix it, and thank you in the release notes if you'd like.

## Supported versions

We fix security problems in the latest version of each project.
